# ICARE Arena

**Amateur esports tournaments, 1v1 matches and live prediction markets, settled in USDC on Base.**

ICARE Arena connects amateur multi-game tournaments, public match broadcasts and prediction markets. ICARE follows live streamers, opens a Win / Lose market on each game, and an AI referee reads the stream to settle it, with a proof published on IPFS and on Base. 18+; availability depends on jurisdiction.
